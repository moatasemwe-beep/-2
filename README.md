# Dynamic Wheel Launcher & Theme Studio

مشروع Flutter لأندرويد يقدّم عجلة تطبيقات دائرية واستوديو مظهر، مع تكامل Kotlin أصلي للتطبيقات المثبتة والخلفيات.

## ما يتضمنه المشروع

- عجلة تطبيقات تحسب المواضع باستخدام `sin` و`cos`، وتدعم السحب والتدوير مع قصور ذاتي وتثبيت موضع الأيقونات عند الإفلات.
- قراءة أسماء التطبيقات وأيقوناتها من `PackageManager` وتشغيلها، مع طلب رؤية تطبيقات Launcher فقط عبر `<queries>` بدل صلاحية الوصول الشامل.
- تعيين صورة مختارة كخلفية للشاشة الرئيسية أو القفل أو كلتيهما عبر `WallpaperManager`.
- تدوير دوري للخلفيات بواسطة `WorkManager`، مع خيار إضافي لمحاولة التدوير عند فتح القفل إذا استلمت عملية التطبيق الحدث.
- ساعة رقمية أو بعقارب، اختيار الخط الرقمي، توهج، وألوان جاهزة. يمكن أخذ لون إبراز تقريبي من صورة الخلفية المختارة.
- أقنعة دائرية ومربعة ناعمة وسداسية للأيقونات داخل العجلة.

## المتطلبات والبناء

- Flutter 3.35 أو أحدث، Android SDK وAndroid Studio/Command-line tools، وJava 17.
- الحد الأدنى المدعوم في هذا المشروع: Android 8.0 (API 26).

من مجلد المشروع:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

لبناء APK تجريبي:

```bash
flutter build apk --debug
```

ولنسخة توزيع، أضف إعداد توقيع Release خاصًا بك في `android/app/build.gradle.kts` بدل مفتاح debug الموجود في قالب Flutter.

## جعل التطبيق الشاشة الرئيسية

ثُبّت التطبيق ثم افتح إعدادات الهاتف واختر: **التطبيقات ← التطبيقات الافتراضية ← تطبيق الشاشة الرئيسية / Home app ← Dynamic Wheel Studio**. قد تختلف أسماء القوائم بين الشركات. بعد الاختيار، سيعرض النظام التطبيق عند الضغط على زر Home. الرجوع إلى مشغّل آخر يتم من القائمة نفسها.

## ملاحظات مهمة عن Android

- التطبيق **Launcher** وليس بديلًا لشاشة القفل. لا يملك تطبيق عادي صلاحية إحلال واجهة قفل نظامية كاملة؛ هنا يغيّر `WallpaperManager` صورة الخلفية فقط.
- WorkManager لا يضمن التنفيذ في الدقيقة المحددة: الحد الأدنى للعمل الدوري 15 دقيقة، وقد يؤخر Android التنفيذ لتحسين البطارية أو بسبب قيود الشركة المصنّعة. لذلك اختر الفاصل كحد أدنى لا كتوقيت دقيق.
- خيار فتح القفل أفضل محاولة لا ضمانًا. `ACTION_USER_PRESENT` يُسجّل هنا كمستقبل ديناميكي أثناء بقاء عملية النشاط حية؛ إذا أوقف النظام العملية فقد لا يصل الحدث. لا يعتمد التدوير الدوري على هذا الخيار.
- تغيير شكل أيقونات تطبيقات النظام الأخرى غير متاح من Launcher عادي؛ الأقنعة هنا تخص الأيقونات التي يرسمها هذا التطبيق فقط.
- الألوان والخطوط والأقنعة في هذه النسخة محفوظة في حالة التشغيل؛ إعداد الصور والجدولة تُحفظ محليًا في Android وتُستعاد عند فتح التطبيق.
